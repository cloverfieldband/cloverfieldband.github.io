ASSETS FOLDER
=============

Put your media files in this folder, then type their file names into
band-info.js (one folder up). File names must match exactly,
including capital letters and the extension (.mp4, .jpg, .png).

WHAT GOES HERE

  clip.mp4        The performance clip that plays on the page.
                  - MP4 format (what phones and most editors export by default)
                  - 15 to 45 seconds is ideal
                  - Try to keep it under 10 MB so it loads fast on phones
                  - Shape (wide, vertical, etc.) is set in band-info.js

  poster.jpg      A still frame from the clip, shown before it plays.
                  Same shape as the clip. JPG, under 300 KB.

  logo.png        OPTIONAL. Only if you want a logo image instead of the
  (or .svg)       typed "Clover Field" name. Transparent background works best.

  share.jpg       OPTIONAL. The picture that shows when someone shares the
                  link in a DM or text. 1200 x 630 pixels. See the
                  "LINK PREVIEW" note at the top of index.html. That
                  one is set after the site is online.
